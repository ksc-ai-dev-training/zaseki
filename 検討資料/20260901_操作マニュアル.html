1. 共通操作（全員）

1.1 ログイン（S-01）

  1. ログイン画面で「Googleでログイン」ボタンを押します。
  2. 会社の許可されたドメインのGoogleアカウントでログインしてください。許可されていないドメインのアカウントを使うとエラーが表示されます。
  3. 初回ログイン時は、Googleアカウントの氏名から姓・名が自動的に登録されます（一括登録は行われないため、最初にログインした人から順に登録されます）。氏名に誤りがある場合は管理部に連絡してください（権限・役割管理〔S-08〕から訂正できます）。

1.2 マイプロフィールの設定（S-12）

サイドバーの「マイプロフィール」から、自分のアイコン画像・生年月日（月日のみ）を登録できます（任意項目）。

  1. アイコン画像を設定すると、以降は空き状況・予約（S-02）や座席状況の履歴照会（S-10）の座席タイル、サイドバー下部の自分の表示に、氏名とあわせてそのアイコンが表示されます。未設定の間は氏名の頭文字によるアバターが代わりに表示されます。
  2. 生年月日（月日）を登録すると、登録した月日が本日と一致する日に、自分が使用している座席タイルに誕生日バッジ（🎂）が表示されます。年は登録しません。
  3. いずれの項目もいつでも変更・削除できます。画像には容量・形式の制限があるため、対応形式以外や大きすぎるファイルを選ぶとエラーが表示されます。

1.3 座席の予約・取消（S-02、フロアマップ表示）

  1. サイドバーの「空き状況・予約」（トップ画面）を開きます。
  2. 上部の日付選択（前日／翌日／今日ボタン、または日付を直接入力）で予約したい日を選びます。
  3. 表示モードタブ（全体表示／NORTHエリア／EASTエリア／WESTエリア）でエリアを切り替えられます。全体表示は縮小表示のため、実際に座席番号を確認して予約する場合はエリア単体タブの利用をおすすめします。
  4. 空いている座席（オレンジ系の「空き」表示）をクリックすると予約確認ダイアログが開きます。内容を確認して予約を確定します。
  5. 複数の日に同じ座席を確保したい場合は、予約確認ダイアログの「繰り返し予約にする」にチェックを入れると、繰り返しパターン（毎日／毎週・曜日を複数選択）と適用終了日を指定できます。
  6. 自分の予約（濃いオレンジ系表示）をクリックすると取消確認ダイアログに切り替わります。
座席タイルの表示ルール: 使用中・固定座席・自分の予約・プロジェクト座席（個人確定済み）は、座席番号ではなく利用者の姓を表示します（アイコン登録者は姓とあわせてアイコンも表示）。同じフロア・同じ日に同じ姓の利用者が複数いる場合のみ、該当するタイルは「姓（名の頭文字）」の形式に自動的に切り替わり区別できるようになります（例: 岩崎（遼）・岩崎（弘））。1人しかいない姓は通常どおり姓のみの表示です。プロジェクト座席で誰にも確定していない座席（未確定）は、個人名ではなくプロジェクトの略称を表示します。

1.4 空き状況を一覧で確認する（S-02、期間ビュー）

  1. フロアマップ表示の上にある「期間ビュー」タブに切り替えます。
  2. 表示期間（開始日〜終了日）を指定すると、日付×座席のグリッド形式で空き状況をまとめて確認できます（既定は予約可能期間全体）。日付ごとの予約数・空席数も左側に表示されます。
  3. 各セルの「空き」ボタンから、その日・その座席を直接予約できます（フロアマップ表示と同じ予約確認ダイアログが開きます）。
  4. 座席数が多く見づらい場合は、エリア単体タブに切り替えると列数を絞り込めます。

1.5 自分の予約の確認・変更・取消（S-02）

座席表（フロアマップ表示・期間ビューいずれの場合も）の下に「自分の予約」一覧があります。

  1. 「今後の予約」「過去の予約」タブで切り替えます。表示期間や並び替え・種別での絞り込みも可能です。
  2. 今後の予約の各行には「変更」「取消」ボタンがあります。「変更」を押すとその予約の日付・エリアのフロアマップへ自動的にスクロールします（専用の変更フォームはなく、その場で取消して別の座席を予約し直す形で変更します）。
  3. 「取消」を押すと確認ダイアログが表示され、確定すると予約が取り消されます。

2. PM・PL向け操作（プロジェクト座席、S-04）

プロジェクトのPM・PL、および後述の「席決め」権限を付与されたメンバーが行う操作です。サイドバーの「プロジェクト座席」から開きます。複数プロジェクトのPM・PLを兼務している場合は、プロジェクトごとにセクションが分かれて表示されます。

2.1 対象四半期の切り替え

画面上部の四半期タブから、自分の所属プロジェクトに計画が存在する四半期を選べます。初期表示は最も新しい四半期です。計画がまだない四半期を選ぶと「この四半期の計画はありません」と表示されます。

2.2 出社曜日アンケートへの回答

  1. 該当プロジェクトのセクションに「出社曜日アンケートの回答」があれば、第一希望・第二希望（それぞれ曜日を2つ）を選んで回答します。両方の希望に同じ曜日を含めても構いません。
  2. 備考（管理部・エリア責任者への伝達事項）と、必要座席数の変更希望（任意）もあわせて入力できます。変更希望を入力すると、管理部・エリア責任者の確認を介さず自動的に必要座席数へ反映されます。
  3. 回答すると内容は折りたたみ表示になります。「表示する」で回答内容を確認、「非表示にする」で再度折りたたみ、「回答を修正する」で編集フォームを開けます。曜日が確定するまでは何度でも回答を修正できます。

2.3 メンバー管理（席決め権限）

PM・PL本人のみが操作できます。メンバー一覧の「席決めを任せる」チェックを入れると、そのメンバーにも下記2.4・2.5の座席確保操作を任せられます（管理部の承認は不要）。自分自身の行にはこのチェックは表示されません。

2.4 メンバーへの座席確保

座席の島の割当が完了した四半期（管理部・エリア責任者が実施）に限り、PJ席決担当または席決め権限を持つメンバーがこのパネルを操作できます。

  1. メンバー一覧の「割り当てる座席」列のプルダウンから、割り当てられた座席の島の範囲内の座席を選びます。
  2. 複数名分をまとめて選んでから「この内容で一括確保する」を押すと、確定した出社曜日・対象四半期に沿って周期予約としてまとめて確保されます。
  3. 座席表を見ながら選びたい場合は「座席表から選ぶ」ボタンから空き状況・予約（S-02）のフロアマップへ移動できます。フロアマップは対象四半期の開始日（10/1・1/1・4/1・7/1のいずれか）を初期表示します。座席の島の範囲内かつ未確定の座席をクリックすると、割り当てる相手を選ぶモーダルが開きます。複数名を選んでから「この内容で確保する」で確定し、プロジェクト座席画面に戻ります。
  4. 同じ座席を複数のメンバーに指定した場合、その組み合わせだけが確保対象から除外されます（他のメンバーは確保されます）。結果は一覧で確認できます。

2.5 在宅のため座席が不要なメンバーの設定

ずっと在宅勤務でプロジェクト座席が不要なメンバーがいる場合、メンバー一覧の「在宅のため不要」チェックを入れます。

  • チェックを入れたメンバーは、固定座席を既に持っているメンバーと同じ扱いで、座席選択欄が「対象外（在宅のため不要）」表示に変わり、確保対象・未確保者数から除外されます。
  • 既に座席を確保済みのメンバーの行はチェックボックスが非活性になります。先にその予約を取り消してから設定してください（チェックを入れても既存の予約は自動では取り消されません）。
  • チェックはいつでも外せます。
  • 固定座席保有者と同様、必要座席数（S-09）の算出にも反映されます。メンバー全員が固定座席保有者・在宅のため不要のいずれかになったプロジェクトは、S-09側で「座席不要（全員固定座席／在宅）」と表示され、アンケート送信〜座席の島の割当自体が不要になります。

2.6 固定座席保有者の扱い

既に固定座席（S-05で管理部が指定）を持つメンバーは、そもそもプロジェクト座席が不要なため、座席選択欄を表示せず「対象外（固定座席保有者）」と表示されます。特別な操作は不要です。

2.7 前回サイクルの参照

「前回分を見る」リンクから、直近1サイクル（3か月）前の座席の島・メンバー割当の内容を参照専用で確認できます。今回の出社曜日・座席割当の検討の参考にしてください。

3. 管理部・エリア責任者向け操作

3.1 プロジェクト座席の運用（S-09）

サイドバーの「プロジェクト座席（エリア担当）」、または管理メニューから開きます。管理部（role='admin'）であれば、エリア責任者・副責任者に指定されているかどうかを問わず操作できます。

  1. 四半期計画データは対象四半期の開始の2か月ほど前を目安にシステムが自動的に作成するため、開始操作は不要です。一覧の対象四半期タブは初期表示で最も新しい四半期が自動選択されます。
  2. 一覧には状態（アンケート未送信／アンケート中／曜日確定済み／座席割当済み、または全員固定座席保有者・在宅のため不要の場合は「座席不要」）が表示されます。必要座席数は、プロジェクトメンバーのうち固定座席を持たない、かつ在宅のため不要に設定されていない人数から自動算出されるため、通常は入力不要です。例外的に上書きしたい場合のみ「人数を修正」を使います（座席の島の割当前まで）。
  3. 「アンケートを送る」で、対象プロジェクトのPM・PLへ出社曜日アンケート（第一希望・第二希望）の回答を依頼します。送信すると共通のSlackチャンネルへ通知が送られます（Webhook URL未設定の場合は送信されません）。未回答のプロジェクトが残っている場合は、任意のタイミングで手動リマインドを送信できます。
  4. 出社曜日の確定は、画面下部の「曜日×プロジェクト」のマトリクス表で行います。全プロジェクトの回答（①第一希望・②第二希望のバッジ付き）を見比べながら、各プロジェクトのセルを自由にチェックし（希望外の曜日をチェックすると「例外」バッジが付きます）、確定操作でまとめて反映します。確定すると共通のSlackチャンネルへ通知が送られます。
  5. 曜日確定後・座席割当後のプロジェクトは、マトリクス表の対象外になり、代わりに直後の「確定した出社曜日」表（参照専用、調整表と同じグリッド形式）で確認できます。過去の四半期タブに切り替えれば、その四半期の確定内容も同様に確認できます。
  6. 座席の島の割当は、一覧の「座席の島を割り当てる」から空き状況・予約（S-02）のフロアマップへ移動して行います（初期表示日は対象四半期の開始日）。必要座席数ちょうどの空きブロックがあれば、ブロックのラベルの「この島を割り当てる」ボタンでまとめて選べます。座席単位でも選べるため、1つのブロックに複数の小規模プロジェクトを同居させることもできます。選び終えたら確定し、プロジェクト座席（S-09）に戻ります。
  7. 既に割当済みの座席の島は「座席を編集」から選び直せます。範囲から外したことでメンバー個人の確保が失われた場合は、PM・PL側（2.4節）で確保をやり直してもらう必要があります。

3.2 固定座席の指定（S-05）

管理メニューから開きます。

  1. 「対象者検索」（まだ固定座席を持たない利用者向け）または「固定座席利用者一覧」（既存の割当を見直す）から対象者を選びます。
  2. 座席指定モードで空き状況・予約（S-02）のフロアマップに移動し、座席を選びます。
  3. 確認ダイアログで「無期限にする」（既定）か、期限（この日まで）を指定します。期限を設定すると、その日を過ぎると自動的にフリー座席に戻ります。
  4. 確定すると本画面（S-05）に戻ります。
固定座席を持つ利用者は、フリー座席・プロジェクト座席を同時に予約できません（RULE-07）。

3.3 代理予約・取消（S-11）

固定座席の指定・プロジェクトメンバーへの座席確保のいずれにも該当しない、任意の利用者への一時的な代理予約はこの画面から行います。管理メニューから開きます。

  1. 「対象者検索」で登録済みの利用者を選び、代理予約モードで空き状況・予約（S-02）に移動して単発予約・周期予約を行います。
  2. 逆に既存の予約・割当を代理で取り消したい場合は、対象者の氏名・座席種別で検索した一覧（フリー座席・固定座席・プロジェクト座席いずれも対象）から取消／解除できます。固定座席は日付を持たない恒久的な割当のため「解除」と呼びます。

3.4 座席マスタ管理（S-07）

管理メニューから開きます。

  • 座席の追加・編集（座席番号、所属エリア、座席タイプ）を行います。
  • 「廃止」は状態を切り替えるだけで予約履歴・一覧には残ります。「削除」は座席データ自体を完全に消す操作で、確認ダイアログを経て行いますが、予約履歴または固定座席の割当が残っている座席は削除できません（廃止を案内するメッセージが表示されます）。
  • 「座席表に配置する」から空き状況・予約（S-02）へ移動し、座席配置モードで実際のフロアマップ上の空いている位置に座席を配置できます（配置図上の位置が未定の座席は、フロアマップ下部の「追加座席」欄に別枠で一覧表示され、そのまま予約・固定座席指定等の対象になります）。

3.5 権限・役割管理（S-08）

管理メニューから開きます。4つのタブがあります。

  • 利用者ロール管理: 利用者検索、役割（一般／管理部）の編集、氏名（姓・名）の訂正、雇用形態（社員／AB／BP）の設定、在籍状況（在籍中／休職中／退職済み）の設定、役割マスタのラベル付与、エリア責任者・副責任者の指定（なし／エリア責任者／副責任者。特定のエリアには紐づきません）を行います。在籍状況を「退職済み」に変更すると、確認ダイアログを経て当該利用者の固定座席の割当解除・今後の予約の取消もあわせて行われます。
  • プロジェクト・PM管理: プロジェクトの追加・編集・削除、メンバーごとのPM／PL／SL設定、PJ席決担当（PM・PLのいずれか1名）の選択を行います。削除は確認ダイアログを経て行い、メンバー構成・四半期ごとの座席計画（アンケート回答・座席の島の割当を含む）もあわせて削除されます。
  • 通知設定: 出社曜日アンケート関連のSlack通知先（Incoming Webhook URL、プロジェクト座席共通の1つ）を設定します。未入力の場合は通知を送信しません。
  • 役割マスタ管理: 役割名（ラベル）自体の追加・編集・削除を行います。

3.6 座席状況の履歴照会（S-10）

管理メニューから開きます。日付を指定して検索すると、その日の座席状況をS-02と同じフロアマップ形式（参照専用、座席タイルをタップしても何も起きません）で確認できます。照会できる日付は直近1か月以内に限られ、範囲外を指定するとエラーになります。
