Zaseki 画面モックアップ一覧

本社座席予約システム（Zaseki）の画面モックアップ（静的HTML）です。各カードをクリックすると画面イメージを確認できます。

S-01ログイン
全員
Google認証（許可ドメイン: kogasoftware.com）によるログイン。
S-02空き状況・予約
全員
日付・エリア別の空き状況確認と予約登録・変更・取消。周期予約、自分の予約一覧、期間ビューも同画面。
S-02空き状況・予約（スマホ表示）
全員
S-02をスマホ幅（390×844）の枠内に表示したもの。別実装ではなくCSSのメディアクエリのみで切り替わる。フロアマップはピンチで拡大・縮小できる。
S-04プロジェクト座席
PM（PL）
出社曜日アンケートへの回答、メンバーへの代理予約、「席決め」権限の付与・剥奪。
S-05固定座席の指定
管理部
固定座席利用者の座席の指定（登録・変更・取消）。
S-06管理メニュー
管理部
各管理画面への入口。座席数・予約状況等のサマリー表示。
S-07座席マスタ管理
管理部
座席の追加・編集・削除（廃止）。
S-08権限・役割管理
管理部
利用者ロール、プロジェクト単位のPM・PL・SL、エリア責任者・副責任者、役割マスタの管理。
S-09プロジェクト座席（エリア担当）
管理部エリア責任者・副責任者
担当エリア割当、必要座席数の確認、出社曜日アンケートの実施・調整、座席範囲の割当。
S-10座席状況の履歴照会
管理部
過去（直近1か月）の座席状況を参照専用で確認。
S-11代理予約・取消
管理部
フリー座席の代理予約、および座席種別を問わない代理取消・解除。
S-12マイプロフィール
全員
自分のアイコン（任意の画像）・生年月日（月日のみ、任意）の登録・編集。
